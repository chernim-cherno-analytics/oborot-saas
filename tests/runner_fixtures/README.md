# Фиктивные наборы для tests/test_runner.py

Каждый файл — минимальный «набор тестов», который ведёт себя ровно одним
способом: печатает (или не печатает) отчёт и возвращает известный код.
Раннер не должен уметь отличать их от настоящих наборов — в этом и смысл:
приговор выносится по отчёту и коду возврата, а не по имени файла.

Ни один из них не поднимает приложение, не слушает порт и не пишет в базу.
